If you approve, Ferrowarden generates a random new password and stores it on the item as a pending value; the current password stays in place. The agent then sets the new password at the service and tells Ferrowarden to commit it, which makes it the password and keeps the old one in the item's password history. The agent never sees either password. This approval covers this one rotation; committing or aborting it needs no second approval, and a change you make to the item in the meantime is never overwritten: edits of its notes or other fields are kept, and if you change its password, a commit is refused (an abort is always possible).
