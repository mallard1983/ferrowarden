HTTPS is required

This page accepts the vault master password, so Ferrowarden only serves it over an encrypted connection. This request arrived over plain HTTP, so the sign-in form is not shown.

To fix this, do one of the following:

  • Put a reverse proxy with a TLS certificate in front of this port, add the proxy's address to trusted_proxies, and make it send X-Forwarded-Proto: https.
  • Enable TLS for Ferrowarden itself (tls_enabled); the UI listener then uses the same certificate.
  • For a local test only, set ui.insecure_http = true (FERROWARDEN_UI__INSECURE_HTTP=true).

See docs/admin-ui.md.
